# ANI-RSS

🥰 基于 RSS 自动追番、订阅、下载、刮削、整理。

🥰 使用说明：

1. 安装时填写 Web 端口（默认 7789）；安装完成后浏览器访问 `http://本机IP:端口` 即可进入 Web 管理界面
2. 默认管理员用户名 `admin`、密码 `admin`，登录后请立即修改
3. 全部 RSS / 下载 / 刮削 / 通知等配置在 Web 界面完成；如需重置配置，可卸载时选择"删除数据"后重装
4. 本软件依赖 Java 17 环境，优先调用 java-17-openj9，缺失 openj9 时回退 java-17-openjdk

📖 详细文档：<https://docs.wushuo.top/start>

## 功能特性

- 📡 多 RSS 订阅源自动追番（蜜柑、Mikan、动漫花园、动漫之家、Bangumi 等）
- 🧲 自动下载（支持 qBittorrent、Transmission、Aria2 等）
- 🎬 自动刮削（TMDB / Bangumi / 动漫花园）
- 🔔 多种通知方式（邮件、Telegram、Bark、Server 酱、PushPlus、企业微信 等）
- 👥 多用户系统，登录 / 注册 / 邀请码
- 📱 响应式 Web UI，PC 与移动端自适应
- 🪄 RSS 解析、剧集自动识别、重命名、整理入库

## 部署说明

### 一键安装（推荐）

1. 在 fnOS 应用中心"本地安装"上传 `AniRSS-<版本号>-all.fpk`
2. 填写 Web 端口（默认 7789），选择内存模式（低 / 高）
3. 等待安装完成
4. 浏览器打开 `http://飞牛IP:7789`，默认账号 `admin/admin`

### 卸载

- 保留数据：仅卸载程序，配置 / 订阅 / 书源等数据保留在 `应用文件/AniRSS` 下，重装可恢复
- 删除数据：完全清理（jar、config.v2.json、logs 等）
